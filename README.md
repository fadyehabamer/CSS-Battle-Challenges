## How to use

Each folder contains one self-contained solution (an HTML snippet with inline `<style>`). Open the target link, paste the file's contents into the CSSBattle editor and compare with the target.

To view a solution locally, open its `.html` file in a browser. The canvas on CSSBattle is 400×300, so local results may be laid out differently.

> **Note:** don't add `<!DOCTYPE html>` to these files. Several solutions use unitless lengths (e.g. `width: 100;`), which browsers only accept in quirks mode.
